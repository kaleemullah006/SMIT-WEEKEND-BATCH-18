div

div ka maqsad hota hai division ya hisa. HTML mein div ek block-level element hota hai jo web page ke content ko group karne ke liye use hota hai. Yeh ek container ki tarah kaam karta hai jisme aap text, images, aur other HTML elements ko organize kar sakte hain. Div ka use karke aap apne web page ke layout ko better tarike se manage kar sakte hain aur CSS ke through styling bhi apply kar sakte hain. group bnane k liye use hota hai

span

span ka maqsad hota hai ek chhota hissa ya tukda. HTML mein span ek inline element hota hai jo text ke chhote hisson ko group karne ke liye use hota hai. Yeh ek container ki tarah kaam karta hai jisme aap text ke specific parts ko select kar sakte hain aur un par CSS styling apply kar sakte hain. Span ka use karke aap apne web page ke text ko better tarike se manage kar sakte hain bina uske layout ko badle.

iframe

iframe kisi web site ko apni web site me embed krne k liye use hota hai. iska full form inline frame hota hai. iska use krke hum kisi bhi dusri website ko apni website me dikha skte hain. iska use krke hum apni website me youtube video, google map, ya kisi bhi dusri website ka content dikha skte hain. iframe ek HTML element hota hai jo ek alag HTML document ko apni web page me embed krta hai. iframe ka use krke hum apni website me kisi bhi dusri website ka content dikha skte hain bina us website ko khole.
